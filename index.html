About Me

I'm a licensed Electronics Engineer (ECE, ECT) from San Pablo City, Laguna, Philippines, and a graduate of Laguna State Polytechnic University. I'm drawn to the full loop of building something: designing the circuit, writing the code that drives it, and shipping it somewhere people can actually use it. My undergraduate thesis was a Raspberry Pi based medicine dispensing system with RFID authentication, built for our university clinic. Since then I've focused on combining electronics with software, including training and deploying a TensorFlow image classification model to production and building IoT dashboards that connect embedded sensors to live web interfaces. I've also worked through real deployment challenges like Docker configuration, memory optimization, and dependency conflicts to get projects running reliably in production. I'm currently expanding into AI/data engineering and network engineering (MikroTik certified, with working knowledge of Cisco), and I'm open to remote, onsite, or hybrid roles where I can keep building things end to end.
